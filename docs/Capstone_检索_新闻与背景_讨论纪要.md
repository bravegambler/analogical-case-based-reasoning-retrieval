# Capstone 检索：新闻、市场背景与训练目标 — 讨论纪要

**日期（起草）：** 2026-04-27  
**用途：** 记录当前共识与待办，便于后续讨论与落地。

---

## 一、问题意识（你的核心想法）

1. **单靠公司新闻的局限**  
   从投资直觉看，仅凭单条/短期新闻，很难与「可交易结果」或「历史案例是否相似」建立稳定关系；同一则消息在不同**价格路径与预期水平**下含义可以相反（例：业绩好但已大涨 vs 已大跌 → **预期差**不同）。因此，**缺少「已实现的价与估值状态」时，单学新闻容易接近噪声。**

2. **简单多模态尝试的局限**  
   在 `price_concat_eval` 中，用数值向量（如过去 N 日价 + 与新闻 embedding 拼接、调 α）做检索，是合理的第一步探索，但**效果不明显**——可能原因包括：与 BGE 预训练表示空间不自然、信号弱、与评测/GT 对齐不足等。

3. **拟采用的方向：背景文本化 + 与新闻联合表示**  
   - 用 **2–3 年** 量级的**股价**与**基本面**（如 PE），在**较粗时间粒度**上（如周线/月线收价；基本面如季度/三个月频）经 **LLM 总结成一段「市场/公司状态」类文本**（可结构化、少自由发挥，以降低胡编风险）。  
   - **新闻与背景不割裂**：将 **「新闻 + 背景」** 作为**一个整体**写入同一检索/训练 pipeline（拼接或你后续选择的融合方式），**避免**只训新闻、只在检索端临时拼背景，否则与「可学习的是联合模式」的假设不一致。  
   - 仍以 **DTW 匹配**作为 **正例关系**（何者与何者「在价格轨迹上相似」）→ 用**对比学习**拉近对应的 **(新闻+背景) 文本** 的向量表示，再 **fine-tune BGE**，最后用 BGE 做检索。

4. **训练哲学**  
   你认为模型应学到的是 **「新闻 + 背景」的联合模式**，而不是孤立新闻；这决定了 **query 与 doc 的构造应在训练和推理中一致、对称**（除非有明确非对称设计并另作论证）。

## 二、反馈与须保持清醒的前提（供对照）

1. **DTW 是「价序列空间」的 ground truth，不是「文本真值」**  
   用 DTW 定义谁与谁是正例，是在用**轨迹相似**去监督**文本表示**的靠近。这是一条常见但需明说的路：**distant / weak supervision**。  
   **含意：**  
   - 正例在文本上**未必**总相似（同形异故事、同故事异轨迹都可能）。**噪声正例**是预期的，需靠**数据量、负例设计、硬负例、与消融**来压。  
   - 不否定该方案，但**论文/报告叙述**中应写清：**优化目标 = 在文本空间对齐「与 DTW 一致的历史相似性」的代理，而非「文本ground truth 的本体」**。

2. **评测与训练要对齐**  
   若线下 Recall/NDCG 仍基于**同一套 DTW 或同一标签逻辑**，与对比学习目标一致，叙事才顺；若以后换标签，需同步说明。

3. **LLM 摘要：收益与风险**  
   - **收益：** 全链路文本化，**与 BGE 的分布**更自然；可审计、可 debug。  
   - **风险：** 事实错误、不稳定性。建议**结构化 + 关键数字从数据填充**、**低温/可复现**、**校验规则**，再进入对比学习。

4. **简单数值 concat 与「摘要 + BGE」的关系**  
   后者在工程上更重，但**有理由**期待更稳定信号；**不保证**分数暴涨——瓶颈仍可能在 **弱监督噪声、任务定义、语料与键对齐** 等（与此前 pipeline 中已知风险一致）。

## 三、简单执行计划（供明天细化的骨架）

> 以下顺序可调整；建议**先小样本**验证再全量。

| 阶段 | 内容 | 产出/检查点 |
|------|------|------------|
| **A. 数据与 schema** | 固定「背景」文本模板（如：长周期趋势、区间、PE 分位/相对等）；粗粒度时序与截止时间（query 前无信息泄漏）。 | 一两页 schema + 若干手工抽检样本。 |
| **A'. 生成** | 用 LLM 或「规则+少量生成」产背景段；**新闻+背景** 合成一条训练/索引文本。 | 小表：ticker-窗口-文本 长度与样例。 |
| **B. 对齐现有管线** | 与现有 `config`、`step04` 对、嵌入目录、`step07` 评估键（Window_End / query 日）**同一策略**；明确 query/doc 均使用「联合文本」。 | 与 `step07` 或单独 eval 可跑的 smoke run。 |
| **C. 训练** | 以 DTW 对为正例的对比学习，细调 BGE；设计负例（随机窗、同 ticker 异窗、**DTW 不相似**等硬负例）。 | `metrics.csv` / 子集 R@k；checkpoint 选优（避免只看 train loss）。 |
| **D. 检索与消融** | 全量 R@k、NDCG；**消融**：仅新闻、仅背景、联合；可选与旧 `price_concat` 数值线对照。 | 主表 + 一段「弱监督+联合表示」的叙事。 |
